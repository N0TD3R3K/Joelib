# JOESE assets

Keep launch artwork in the existing subfolders:

- `logos/` — approved JOESE and listing marks;
- `icons/` — custom interface icons not provided by the shared icon set;
- `lore-images/` — fictional Joe Wire and company artwork; and
- `email-templates/` — reviewed transactional-email source assets.

Do not place secrets, member uploads, or unlicensed third-party artwork here.
