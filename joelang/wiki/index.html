The Joe Programming Language

The Chronicles of Joe: An absurdist narrative, dynamically typed, single-threaded programming language where every program reads like a biographical chapter in the chaotic, mundane, yet completely Turing-complete life of a guy named Joe.

"In JoeLang, programs are not compiled into cold silicon instructions. They are endured by Joe as a series of mental episodes, routines, and existential crises."

1. Overview & Philosophy

JoeLang rejects sterile C-style semicolons and keywords. Instead of let, while, if, and return, a JoeLang program describes what Joe remembers, worries about, believes, delivers, or screams into the void.

  • Literary Syntax: Programs are written as grammatical English sentences ending with periods (.) and colons (:).
  • First-Class GC: Backed by dumpster, JoeLang natively tracks cyclic reference graphs (e.g., codependent social circles) and cleans them up automatically.
  • Three Personas Tooling:
    • joe: The Executor, documentary Narrator (--narrate), and Interactive REPL.
    • cjoe: Joe's Conscience, a semantic reality checker flagging amnesia and existential errors.
    • djoe: Joe's Therapist, an interactive step debugger to guide Joe through his mental crises.

2. Quickstart

Compile the binaries using Cargo:

cargo build --release

Run a script:

cargo run --bin joe -- examples/morning_routine.joe

Run with documentary voiceover mode:

cargo run --bin joe -- --narrate examples/fibonacci.joe

Check code consistency with Joe's Conscience:

cargo run --bin cjoe -- examples/troubled_joe.joe

Enter an interactive therapy session (debugger):

cargo run --bin djoe -- examples/morning_routine.joe

3. Narrative Syntax Reference

Traditional Construct JoeLang Narrative Syntax Description
let x = 10; Joe remembers x as 10. Declares and initializes a variable in current scope.
x = 20; x turns into 20.
or Joe sets x to 20.		 Mutates an existing variable or field.
println(msg); Joe yells msg. Prints text with a trailing newline.
print(msg); Joe whispers msg. Prints text without trailing newline.
let s = read(); Joe listens to s. Reads a line from standard input into s.
if cond { ... } else { ... } If Joe believes cond: ... Otherwise: ... That is that. Conditional branching block.
while cond { ... } While Joe worries about cond: ... Joe moves on. Loop while condition evaluates to truthy.
for item in list { ... } For every item in list: ... Joe moves on. Iterate over list, string characters, or bag keys.
break; Joe gives up. Exits the innermost loop immediately.
continue; Joe tries anyway. Jumps to next iteration of innermost loop.
fn f(a, b) { return a + b; } To f with a, b: Joe delivers a + b. That's how Joe does it. Declares a function (habit).
return val; Joe delivers val. Returns value from habit.
class Person { ... } Meet a Person: It has name, friend. ... That's a Person. Declares a class archetype with fields and methods.
new Person("A", null) a new Person("A", nothing) Instantiates an object.
this / self jthis Instance reference inside class methods.
import mod; Joe calls for std.math. Loads and imports standard library module.
panic(msg); Joe panics msg. Aborts execution with an existential error.

4. Values & Data Types

Joe's world contains six primary value types:

  • Nothing (nothing): The void / null representation.
  • Agreement (Boolean): Joe agrees represents truth, Joe disagrees represents false.
  • Numbers (f64): Double-precision numbers (e.g. 42, 3.14, -0.5).
  • Text (Strings): UTF-8 string literals enclosed in double quotes (e.g. "espresso"). Supports escapes like \n, \t, \", \\.
  • Lists: Ordered collections enclosed in brackets (e.g. [1, "coffee", Joe agrees]).
  • Bags (Dictionaries): Key-value maps enclosed in braces (e.g. {"roast": "dark", "rating": 5}).

5. Memory & Mutation

Memory in JoeLang is lexically scoped. Joe remembers variables in his current scope, which shadow outer scopes.

Joe remembers savings as 100.
Joe remembers coffee_cost as 4.

// Mutation:
savings turns into savings - coffee_cost.
Joe sets savings to savings - coffee_cost.

Joe yells "Remaining savings: $" + savings.

6. Control Flow

Conditionals

Joe remembers mood as "sleepy".

If Joe believes mood == "sleepy":
    Joe yells "Joe needs a double shot.".
Otherwise:
    Joe yells "Joe contemplates productivity.".
That is that.

While Loops

Joe remembers count as 3.

While Joe worries about count > 0:
    Joe yells "Ticking down: " + count.
    count turns into count - 1.

    If Joe believes count == 1:
        Joe yells "Joe cannot take it anymore!".
        Joe gives up. // break
    That is that.
Joe moves on.

For Loops

Joe remembers tasks as ["wake up", "brew coffee", "exist"].

For every task in tasks:
    Joe yells "Task: " + task.
Joe moves on.

7. Habits (Functions)

Functions in JoeLang are referred to as Habits. They support recursion, closures, and first-class assignment.

To add_beans with amount, extra:
    Joe delivers amount + extra.
That's how Joe does it.

Joe remembers total as add_beans(5, 2).
Joe yells "Total beans: " + total.

8. Social Archetypes (Classes)

Classes represent types of people or things Joe encounters:

Meet a Person:
    It has name, friend.

    To introduce with greeting:
        Joe yells greeting + ", I am " + jthis.name.
    That's how Joe does it.
That's a Person.

Joe remembers alice as a new Person("Alice", nothing).
alice.introduce("Hello").

9. Keyword & Operator Overrides by Classes

Classes in JoeLang can intercept and override core narrative keywords when Joe directs his actions towards a target:

Directing Output: Joe yells ... to <target>.

When Joe directs a yell or whisper to an archetype instance or file, the class method handles it:

Meet a CustomLogger:
    It has prefix.

    To yell with msg:
        Joe yells "[" + jthis.prefix + "] " + msg.
    That's how Joe does it.

    To whisper with msg:
        Joe whispers "(" + jthis.prefix + " quiet) " + msg.
    That's how Joe does it.
That's a CustomLogger.

Joe remembers log as a new CustomLogger("APP").
Joe yells "Server initiated" to log.     // calls log.yell(...)
Joe whispers "Debug heartbeat" to log.  // calls log.whisper(...)

Yelling & Whispering Directly to Files

If the target of a yell or whisper is a file path string, Joe appends directly to the specified file:

Joe yells "Log line with newline" to "audit.log".
Joe whispers "Raw token without newline" to "audit.log".

Binary Operator Overloading

Classes can override standard arithmetic and comparison operators by defining the corresponding habit:

  • + → To add with other: ...
  • - → To sub with other: ...
  • * → To mul with other: ...
  • / → To div with other: ...
  • % → To mod with other: ...
  • == → To eq with other: ...
Meet a Vector:
    It has x, y.

    To add with other:
        Joe delivers a new Vector(jthis.x + other.x, jthis.y + other.y).
    That's how Joe does it.
That's a Vector.

Joe remembers v1 as a new Vector(1, 2).
Joe remembers v2 as a new Vector(10, 20).
Joe remembers v3 as v1 + v2. // Invokes Vector's add method!

10. Declarable Modules

In addition to calling external files or packages via Joe calls for ..., Joe can establish self-contained, first-class modules directly within code:

Joe establishes MathEngine:
    Joe remembers factor as 2.

    To double with n:
        Joe delivers n * factor.
    That's how Joe does it.
That's MathEngine.

Joe yells "Double 8 is: " + MathEngine.double(8).

Modules encapsulate their declarations and export all defined variables, habits, and archetypes as a Bag accessible under the module name.

11. Dumpster GC Model

JoeLang uses dumpster, a single-threaded cycle-tracking garbage collector. In object-oriented programming, circular references often cause memory leaks under naive reference counting.

In JoeLang, cyclic social circles are automatically tracked and reclaimed:

Joe remembers alice as a new Person("Alice", nothing).
Joe remembers bob as a new Person("Bob", alice).

// Alice references Bob, and Bob references Alice:
alice.friend turns into bob.

// When alice and bob leave scope, dumpster detects the cycle
// and reclaims the memory cleanly without manual freeing.

12. "Cup of Joe" Standard Library

All standard library modules are strictly synchronous and single-threaded.

10.1 Global Subconscious (Prelude)

Always available in global scope without importing:

  • len(val): Returns integer length of string, list, or bag.
  • type(val): Returns type name string ("text", "number", "list", etc.).
  • str(val): Converts any value into text representation.
  • num(val): Parses number from string or casts boolean.
  • bool(val): Returns Joe agrees or Joe disagrees based on truthiness.
  • reflect(): Confirms cycle-tracking GC is active.
  • panic(msg): Aborts execution with an error message.

10.2 std.io — Stream & Terminal I/O

Joe calls for std.io.

std.io.println("Standard message").
std.io.eprintln("Error stream message").
Joe remembers answer as std.io.read_line().
std.io.clear_screen().

10.3 std.file — Synchronous File I/O

Joe calls for std.file.

std.file.write("notes.txt", "Day 1: Joe woke up.\n").
std.file.append("notes.txt", "Day 2: Joe bought coffee.\n").

If Joe believes std.file.exists("notes.txt"):
    Joe remembers content as std.file.read("notes.txt").
    Joe remembers lines as std.file.read_lines("notes.txt").
    Joe yells "File lines: " + len(lines).
That is that.

std.file.remove("notes.txt").

10.4 std.net — Synchronous Network HTTP

Powered by ureq without asynchronous overhead. Returns a Response Bag containing status, ok, body, and headers:

Joe calls for std.net.
Joe calls for std.json.

Joe remembers res as std.net.fetch("https://httpbin.org/get").

If Joe believes res.ok:
    Joe yells "HTTP Status: " + res.status.
    Joe remembers data as std.json.parse(res.body).
    Joe yells "Origin IP: " + data.origin.
That is that.

13. Tooling Suite

11.1 joe — The Story Runner & REPL

  • joe <script.joe>: Runs script to completion.
  • joe --narrate <script.joe>: Explains the script using the Narrator (documentary voiceover) alongside execution.
  • joe: Starts the interactive REPL. Type Joe rests. to exit.

11.2 cjoe — Joe's Conscience (Linter / Checker)

Validates scripts for semantic errors before running:

  • cjoe <script.joe>: Emits friendly colored diagnostics.
  • cjoe --ast <script.joe>: Prints structured AST.
  • cjoe --json <script.joe>: Outputs structured JSON diagnostics for IDE and LSP integration.

11.3 djoe — Joe's Therapist (Step Debugger)

Interactive terminal debugger with commands:

Command Shortcut Description
stepsLet Joe take one step forward in life.
continuecLet Joe live until the next breakpoint or termination.
break <line>b <line>Set an existential breakpoint at line.
clear <line>Remove breakpoint at line.
mindlocalsInspect Joe's local variables in current scope.
examine <expr>p <expr>Evaluate expression in current environment.
traumastackInspect the call stack that brought Joe here.
listShow surrounding source code lines.
quitqAbandon Joe to his fate.

Morning Routine

Joe calls for std.math.

Joe yells "--- Joe Wakes Up ---".

Joe remembers bank_account as 30.
Joe remembers coffee_price as 5.
Joe remembers coffees_bought as 0.

While Joe worries about bank_account >= coffee_price:
    bank_account turns into bank_account - coffee_price.
    coffees_bought turns into coffees_bought + 1.
    Joe yells "Joe drank cup #" + coffees_bought + ", remaining funds: $" + bank_account.

    If Joe believes coffees_bought >= 3:
        Joe yells "Joe is vibrating at high frequencies!".
        Joe gives up.
    That is that.
Joe moves on.

Joe yells "Joe survived the morning.".

Recursive Fibonacci

To fib with n:
    If Joe believes n <= 1:
        Joe delivers n.
    Otherwise:
        Joe delivers fib(n - 1) + fib(n - 2).
    That is that.
That's how Joe does it.

Joe remembers target as 10.
Joe yells "Calculating fibonacci(" + target + ")...".
Joe remembers result as fib(target).
Joe yells "Joe calculated fibonacci(" + target + ") = " + result.
